# 車輛紀錄

記錄車子保養和加油的 Windows 小程式，會自動算出油耗。

## 功能

### 加油紀錄
- 每次加油記錄：**日期、里程表讀數、加油量（公升）、金額、是否加滿、備註**。
- 自動算出：
  - **每公升單價**（金額 ÷ 公升）。
  - **到下次加油開了幾公里**（下次里程 − 這次里程）。
  - **油耗（km/L）**：用「加滿法」計算，從這次加滿開到下次加滿，再除以下次加進去的油量。
    中間沒加滿的那次，油量會累計到下次加滿一起算。
- 上方統計：平均油耗、加油總花費、總加油量（含平均單價）、每公里油錢。

### 保養紀錄
- 每次保養記錄：**日期、里程、保養項目、金額、保養廠、下次保養里程（選填）、備註**。
- 下次保養里程可以用「+5,000」「+10,000」快速填入。
- 上方統計：保養總花費、上次保養、距上次保養開了多遠、距下次保養還有多遠（超過時顯示紅字）。

### 其他
- 日期或里程前後矛盾時會提醒（例如較早的日期卻有較高的里程）。
- 數字可以打千分位，也可以用中文輸入法的全形數字。
- 可以匯出或匯入 Excel，一個檔案裡有「加油紀錄」和「保養紀錄」兩張工作表。匯入時會依標題列找欄位，所以欄位順序可以調換。
- 支援淺色、深色、跟隨系統三種主題。
- 線上更新：開啟程式時會檢查 GitHub Releases，有新版會詢問是否更新。

## 安裝

1. 到 [Releases](https://github.com/asdZzz-coder/car/releases) 下載最新的 `CarLog-ClickOnce.zip`。
2. 解壓縮整個 zip。
3. 執行 `安裝.cmd`。

安裝完成後，開始功能表和桌面都會有「車輛紀錄」的捷徑。

資料存在 `%AppData%\CarLog\car.json`，是一般的 JSON 檔，可以直接備份。換電腦時用「匯出 Excel → 匯入 Excel」搬資料。

## 開發

需要 .NET 10 SDK。

```bash
dotnet build car.slnx
dotnet test car.Tests/car.Tests.csproj
dotnet run --project car
```

測試時可以設定環境變數 `CARLOG_DATA_DIR` 改用別的資料夾，就不會動到正式資料。

## 發佈新版本

推送 `v*` 標籤後，GitHub Actions 會依序執行：

1. 跑自動測試。
2. 用 ClickOnce 打包。
3. 把 `CarLog-ClickOnce.zip` 上傳到 GitHub Releases。

```bash
git tag v1.0.0
git push origin v1.0.0
```
